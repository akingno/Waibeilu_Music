# 同听房 · 歪北路音乐

最多五人一起听音乐的私人网页服务，使用共享密码进入一个房间。支持 Chrome 手机和桌面端、MP3 / Ogg 上传删除、1 GB 总容量、在线昵称列表、共享歌单、指定下一首、全员播放控制、单曲循环、均衡随机播放和中途加入自动对齐。

当前已实现本地可运行版本，使用 `yumetohazakura.mp3` 完成上传与浏览器播放验证。尚未部署至 DigitalOcean；手机锁屏、真实跨国线路与五台实体设备的一秒同步指标仍需实测。

## 本地运行

需要 Node.js 24 或更新版本。

```sh
npm ci
```

复制 `.env.example` 为 `.env`，设置自己的 `ROOM_PASSWORD`。默认访问地址 `http://localhost:3000`。

```sh
npm run typecheck
npm run build
npm test
npm start
```

打开浏览器，输入昵称和密码，上传 MP3。所有人都能控制播放及删除音乐。界面切换不会重建音频。房间满员仍可浏览歌单；第六人无法加入收听。

开发后重新执行 `npm run build` 并重启服务。`npm test` 使用最近构建结果，因此修改源码后先构建。测试在 `test-results` 下创建临时数据库并在完成后清理，不改动正式 `data` 或源 MP3。

## 歌单与下一首

1. 点击“新建歌单”，填写名称。歌单显示创建时的昵称，登录成员可共同管理，也可使用“改名”修改名称。
2. 在“全部歌曲”勾选歌曲（或全选搜索结果），选择目标歌单后点击“加入歌单”。浏览某个歌单后，勾选歌曲并点击“从当前歌单移出”；此操作保留音乐文件，每次最多处理 1000 首。
3. 点击“设为播放歌单”更新全房间的播放范围，当前歌曲继续播放；点击歌曲的播放按钮则立即播放，并使用该歌曲所在的浏览歌单。随机播放只选择播放歌单中的歌曲，继续避开最近 3 首并均衡随机次数。空歌单会在切歌时停止，不会改为播放全部歌曲。
4. 在当前播放歌单的歌曲行点击“下一首”，播放器会显示待播歌曲；新设置替换旧设置，也可以取消。手动下一首或当前歌曲自然结束时优先播放一次，随后恢复原播放模式。待播歌曲被删除或移出播放歌单时自动取消。

“全部歌曲”是默认播放范围。歌单、成员关系、当前播放范围及待播歌曲均会保存到 SQLite；重启后恢复暂停，随机次数重新累计。移出歌单与删除音乐库歌曲是两个独立操作，后者会影响所有歌单。

数据库和音乐保存在 DATA_DIR。默认 HTTP + WS，不要求域名或证书。音频读取须有有效收听席位；未授权不能使用直链读取。

手机首次进入或后台恢复时，Chrome 可能要求点击“继续收听”。Media Session 已接入，但操作系统挂起页面后，网页无法保证持续同步或远程唤醒。支持目标包含 iPhone Chrome，Safari 不在适配范围。
